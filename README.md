### 🚀 How to Run

### 1. Create and Activate a Python Environment

First, set up a virtual environment to isolate your project dependencies and install the required packages. 

bash

# Create the virtual environment
python -m venv .venv

# Activate the virtual environment (Windows)
.\.venv\Scripts\activate

# Install the required dependencies
pip install -r requirements.txt


### 2. Run the Server

Once your environment is set up and active, start the development server using the command below: 

bash

python manage.py runserver

### Site sections and age modes

The main navigation has three pages: Home (the landing page), Lessons & Games, and About & Help. About & Help brings together the safety toolkit, parent and teacher guidance, app installation, and support options. Signing in returns to the same Home page; accounts are optional, and learning progress stays in the browser. Lessons & Games combines the seven standalone mini-games—AI or human, fill in the blank, pick and choose, real or fake, password choices, privacy choices, and safer connections—with the seven lessons. Game scores are saved separately from lesson progress in your browser. AI authorship examples explain that style alone cannot prove who created real content. Choose an age mode to see distinct themes, wording, and scam examples across lessons and games; the selected mode, stage preferences, and lesson progress are saved in your browser. Signed-in visitors can open profile customization from the header and spend earned points on avatar gear and pets. A shared animated footer provides site navigation and plain-language privacy, terms, and cookie/storage notices.
